# Список задач — тестовое задание 

Простой todo-лист на React + TypeScript + Vite.

## Возможности

- Добавление задачи через поле ввода и кнопку (Enter тоже работает)
- Пустая задача или задача из одних пробелов не добавляется
- Переключение задачи между выполненной и невыполненной
- Удаление задачи
- Фильтрация: Все / Активные / Выполненные
- Сохранение задач в localStorage — после обновления страницы они остаются
- Выполненные задачи визуально отличаются (зачёркнуты и серые)

## Стек

- React 18
- TypeScript
- Vite
- Обычный CSS (без дополнительных библиотек)

## Запуск

```bash
npm install
npm run dev
```

Открыть: http://localhost:5173/

## Время

~45 минут.
